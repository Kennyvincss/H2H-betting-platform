# H2H-betting-platform

## Overview
The H2H Betting Platform is an innovative solution built on the Solana blockchain. It facilitates head-to-head betting between two users in a fair and transparent way. The platform allows seamless bets, automated payouts, and a 0.5% platform fee on each transaction.

## Features
- **Head-to-head betting**: Two users can compete directly with each other.
- **Low platform fee**: A 0.5% fee is deducted from payouts.
- **Crypto deposits/withdrawals**: Manage funds via Solana-native tokens.
- **Smart Contract-based Escrow**: Ensures secure holding of funds during matches.

## Tech Stack
- **Blockchain**: Solana
- **Frontend**: React.js
- **Backend**: Node.js (Express)
- **Smart Contracts**: Solana programs written in Rust
